**CS 396 Causal Inference**

This project presents an analysis of how officer rank influences penalization outcomes in sustained complaints using Chicago Police Department (CPD) data. We formalized the causal structure using a directed acyclic graph (DAG), applied binary logistic regression to adjust for covariates and confounding, and implemented inverse probability weighting (IPW) to address imbalances across rank and gender. Our findings indicate a trend toward lower disciplinary severity for higher-ranking officers, underscoring the importance of accounting for structural factors in police accountability research.
